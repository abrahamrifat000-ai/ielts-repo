# ielts-repo

Official web application repository for **IELTS with Abraham Rifat - Authentic Cambridge Practice Platform**.

Features:
- Authentic Cambridge Reading Mock Tests (26 Full Scanned Papers with timer, interactive answer sheet, and instant scoring)
- 30 Curated Reading Skill Build-Up Passages with vocabulary notes and summaries
- IELTS Writing Masterclass Hub (Academic Task 1 reports & Task 2 essays)
- Listening Mock Tests & Skill Drills
- Interactive Essay Simulator & Vocabulary Builder
